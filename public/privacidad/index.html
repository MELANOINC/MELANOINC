Política de Privacidad

Última actualización: 26 de agosto de 2026.

MELANO INC utiliza los datos que una persona proporciona voluntariamente en sus formularios o canales de contacto para responder consultas, evaluar necesidades comerciales, coordinar reuniones y realizar seguimiento relacionado con la solicitud recibida.

Datos que podemos recibir

Nombre, empresa, email, teléfono o WhatsApp, mensaje, URL de origen, referencia de navegación y parámetros de campaña cuando existan.

Finalidad

Usamos esos datos para gestionar la relación comercial solicitada, organizar oportunidades, medir el origen de consultas y mejorar nuestros procesos de atención, ventas y automatización.

Base y consentimiento

El envío voluntario de un formulario implica la solicitud de contacto. Cuando el formulario incluye una casilla de aceptación, el usuario debe marcarla antes de enviarlo.

Proveedores e infraestructura

Para operar la web y el seguimiento comercial podemos utilizar proveedores de hosting, bases de datos, automatización, analítica y mensajería. Estos proveedores procesan la información únicamente en el marco necesario para prestar esos servicios.

Conservación y seguridad

Conservamos la información durante el tiempo razonablemente necesario para atender la solicitud, mantener trazabilidad comercial y cumplir obligaciones aplicables. Aplicamos controles técnicos y organizativos para reducir accesos no autorizados, pérdida o uso indebido.

Derechos y contacto

Podés solicitar acceso, actualización o eliminación de datos personales escribiendo a contacto@melanoinc.com. La solicitud puede requerir validación de identidad para proteger la información.

Alcance

Esta política aplica al sitio melanoinc.com y a los formularios institucionales de MELANO INC. Los productos o plataformas con tratamiento específico de datos pueden tener condiciones adicionales.
